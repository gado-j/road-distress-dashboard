# Initial source release

The repository contains a locally runnable dashboard and model API source, not a
hosted webserver. Installation requires a separately supplied compatible model
checkpoint and the user's own Supabase project.

Before manuscript submission:

- Confirm the repository is public and its link works without signing in.
- Have another team member follow README.md from a clean clone.
- Select an approved software license and clarify checkpoint availability.
- Include screenshots from the running application, with clearly described data.
- Report model evaluation metrics only if supported by a proper evaluation;
  startup and prediction timings are not accuracy measurements.

Suggested availability wording once the repository is public:

> The source code for the road-distress web application is available at
> https://github.com/gado-j/road-distress-dashboard. Instructions are provided for
> local deployment; trained model availability is described in the repository.

Future work may include authenticated expert review, hosted deployment, improved
model performance, and video-based inference. These are not current capabilities.
