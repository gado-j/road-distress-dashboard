# Reported YOLO11s validation metrics

The supplied model package reports the following values from an earlier validation run at confidence threshold 0.10. Its original validation images, labels, full evaluation log, and evaluation script were not included in the ZIP, so these numbers have not been independently reproduced here.

| Metric | Reported value |
|---|---:|
| Precision | 58.32% |
| Recall | 72.67% |
| mAP@50 | 63.45% |
| mAP@50:95 | 50.21% |

The package also contains a separate inverse predicted-box-coverage demonstration index. It is not a validated PCI or road-condition score. Detection confidence and box coverage are not crack severity.
